# Security Policy

We take the security of this project seriously. We encourage responsible disclosure of any security vulnerabilities that may be found in the codebase or infrastructure.

## Reporting a Vulnerability

If you believe you have found a security issue, please DO NOT report it publicly (e.g., via GitHub Issues). Instead, please report it privately to our security team.

Please email your report to: `gokceemirhan23@gmail.com`

Include the following details in your report:
*   Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting).
*   Full path of the source file(s) related to the vulnerability.
*   Steps to reproduce the issue.
*   Your name/handle and how you would like to be credited for the discovery.

We will do our best to respond to your report within 48 hours.

## What to Expect

When you report a vulnerability to us, the project maintainers will:
*   Confirm the issue and determine its severity.
*   Work with you to develop a fix and coordinate a responsible disclosure timeline.
*   Give you credit for discovering the vulnerability in the release notes.

Thank you for helping keep this project secure.
